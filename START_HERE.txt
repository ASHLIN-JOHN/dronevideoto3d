TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problems? Check these:

1. Projects not showing?
   → Click Projects tab in sidebar
   → Check browser storage is enabled

2. 3D models not displaying?
   → Go to Scene tab
   → Check Models directory exists
   → Try a different video

3. Video analysis fails?
   → Use MP4 format
   → Keep video under 5 minutes
   → Check disk space available

4. App won't start?
   → Ensure Python 3.8+ installed
   → Check PyQt5 is available
   → Try: python run.py

5. Lost data?
   → Check Projects tab (data in localStorage)
   → Check /projects/ directory (saved scenes)
   → Nothing is deleted, just check other tabs

Still stuck? See QUICK_START.md for more help.
