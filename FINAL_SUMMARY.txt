PROBLEM STATEMENT:
==================
Roads were overlapping, disconnected, and objects were placed on top of them.
The system was generating scenes that looked "clumsy" with improper spacing.

ROOT CAUSES IDENTIFIED:
========================
1. Road network used hardcoded 4.36 spacing instead of actual model size (8.73)
2. Enhancement function added random jitter to road positions
3. No proper collision detection between roads and objects
4. Objects were being placed with no spatial awareness

SOLUTION IMPLEMENTED:
======================

-------------------------------------------------------
- Reads actual model dimensions from metadata.json
- Straightroad model: z=8.73, x=4.16
- Creates 5-segment main spine with EXACT spacing
- Creates 3-segment left branch perpendicular
- Creates 3-segment right branch perpendicular
- Total: 11 connected, properly-spaced road segments

  (Gap between each: 8.73 units - PERFECT!)

-------------------------------------------------------------
- New CollisionDetector class

- Filters objects to remove those colliding with roads
- Removes object-to-object overlaps
